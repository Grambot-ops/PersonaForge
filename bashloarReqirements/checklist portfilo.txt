Check zelf je portfolio op de onderstaande aandachtspunten. Als bepaalde zaken niet in orde zijn, dan doe je eerst de nodige aanpassingen. Het is een goed idee om ook iemand anders te vragen om deze controle uit te voeren. Pas daarna geef je je begeleidende docent toegang tot je portfolio.


0	1. Ik heb een welkomstpagina waar ik de lezer wegwijs maak in mijn portfolio 
0	2. Mijn portfolio bevat op elke pagina een menu met minimaal de volgende items: home, over mezelf, stage, overige projecten 
0	3. Over mezelf bevat mijn contactgegevens, een beschrijving van mijn soft skills en mijn CV (ook apart downloadbaar). Alles wat ik over mezelf schrijf is gericht op mensen uit het werkveld. 
0	4. Stage bevat de titel van mijn stage, een samenvatting en de bewijsstukken die door mijn stagebegeleider werden gecontroleerd 
0	5. Bij overige projecten gebruik ik mijn beste bewijsstukken/realisaties/projecten 
0	6. Ik vermeld voor elk project voldoende context zodat elke lezer de achtergrond kent. De toelichting bij een project is gericht op mensen uit het werkveld. 
0	7. Ik heb elk project voldoende inhoudelijk beschreven en/of getoond zodat het voor de lezer duidelijk is wat ik heb gerealiseerd
0	8. Ik heb bij elk project beschreven wat ik hieruit geleerd heb. Dit is een overtuigend en persoonlijk verhaal. Ik heb geen clichés vermeld die voor om het even wie kunnen gelden.
0	9. Ik heb overal de correcte vakbenamingen gebruikt zoals vermeld in de ECTS-fiches.
0	10. Ik vermeld functies/rollen i.p.v. namen van medestudenten, of docenten of anderen.
0	11. Ik heb dezelfde zaken altijd consequent op dezelfde manier geschreven.
0	12. Alle teksten zijn gecontroleerd met een spelchecker en ik heb speciaal gelet op DT-fouten.
0	13. Mijn portfolio bevat geen gegevens die niet publiek mogen gemaakt worden of die gevoelig zijn. 
0	14. Mijn portfolio is gecontroleerd op basis van deze checklist en nagelezen door (vermeld naam en verwantschap of relatie, geen medestudent!)
